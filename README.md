# Coisini · 角色人格恒定引擎

> **让角色经历几百、几千楼之后，依然是那个角色。**
>
> 允许角色成长，但不允许角色在成长的过程中逐渐变成另一个人。

## 定位

Coisini 是一个 SillyTavern 第三方扩展，守护**人物连续性**（区别于 [Serendipity](https://github.com/lit66731-star/st-serendipity) 守护的故事连续性）。

它不是一个简单的“请不要 OOC”提示词，而是一套持续运行的系统：

```
角色人格模型 → 当前人格状态 → 行为基线 → 生成前约束 → 生成后审计 → 漂移修正
```

| 概念 | 回答的问题 |
| --- | --- |
| 人格核心 Core | 这个人是谁 |
| 人格状态 State | 这个人现在是什么状态 |
| 行为指纹 Fingerprint | 这个人通常怎么做 |
| 漂移检测 Drift | 这个人是不是越来越不像自己 |
| OOC 审计 Audit | 这一楼有没有偏离 |

## 核心原则

- **P1** 角色不能因为上下文变长而逐渐换一个人。
- **P2** 角色卡是人格的起点，不是每轮唯一依据。
- **P3** 人格核心稳定，但人格状态允许成长。
- **P4** 人物变化必须有剧情依据（Change Reason）。
- **P5** 不能把“成长”误判成 OOC。
- **P6** 不能因为模型偶尔一句异常就过度干预。
- **P7** 楼层越高，人物一致性要求越强，而不是越弱。
- **P8** 模型可以忘记细节，但不能忘记“自己是谁”。
- **P9** 不通过无限堆 Prompt 解决问题。
- **P10** 插件本身不能改变角色，只能保护角色连续性。

## 总体架构

```
角色卡解析 → Character Core（人格核心）
                 ├── 人格状态系统
                 ├── 行为指纹系统
                 └── 关系系统
                          ↓
                  场景 / 当前状态
                          ↓
              Generation Guard（生成前守卫）
                          ↓
                       AI 生成
                          ↓
               OOC Auditor（生成后审计）
                          ↓
           正常 / 轻微偏离 / 严重 OOC
              ↓        ↓          ↓
            放行      纠偏      重写/重生成
                          ↓
                    人格状态更新
                          ↓
                    漂移检测
```

## 核心数据结构

```
CharacterProfile
├── core            # 人格核心（角色卡解析所得，稳定）
│   ├── identity / traits / values / principles / immutable
├── personalityState # 当前人格状态（可变：情绪/心理/动机/身体状况）
├── behavior         # 行为指纹（语言/情绪表达/冲突/亲密/决策）
├── relationships    # 关系系统（角色对不同人的不同行为）
├── evolution        # 人格成长时间线（每次变化带剧情依据）
├── context          # 当前场景
├── drift            # 漂移检测
└── violations       # 异常记录（OOC 审计）
```

## 安装

将本仓库放入 SillyTavern 的 `public/scripts/extensions/third-party/coisini/` 目录，或在扩展管理器中导入。

## 配置

`optional: ["serendipity"]` —— 若安装了 Serendipity，后续增量可复用其剧情事件作为“改变事件”来源。
